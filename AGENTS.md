# Project collaboration instructions

## Preserve progress in GitHub

The owner explicitly requests a commit and push for every completed change to this project.

- Commit coherent completed work and push it to the configured GitHub remote before reporting the task finished.
- Include source, required assets, generated HTML, documentation, and reference material when they belong to the change.
- Keep credentials, local environment files, dependency directories, and temporary build files out of Git.
- Verify the pushed commit matches the remote branch. If commit or push fails, report the failure and the remaining local work explicitly.
- Do not discard existing changes or rewrite shared history to make the working tree clean.

## Project identity

The active reconstruction is the Honda F22A6 from a 1993 Accord EX sedan with a 5-speed manual transmission. Market and emissions details remain unresolved. Preserve bilingual Spanish/English support and low vision accessibility.
