# Honda Accord Motor — 3D Render

An interactive 3D render of a turbocharged **Honda F22A6** engine (the 2.2L inline-4 from the 1990s Honda Accord), modeled after the reference image in [`reference/`](reference/honda-f22a6-turbo-reference.jpeg).

## Goal

Recreate the engine in 3D, including the labeled components from the reference:

- Valve cover (HONDA F22A6) and intake manifold
- Garrett turbocharger
- Compressor air outlet (salida de aire)
- Wastegate valve (válvula de descarga)
- Exhaust manifold with the turbo mounted on it (colector de escape)
- Exhaust outlet / downpipe (salida de escape)
- Alternator, belt and pulleys, engine block and oil pan
